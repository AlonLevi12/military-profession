# לומדת המקצוע הצבאי 

מערכת Web אינטראקטיבית בעברית וב־RTL ללמידה עצמית של שלושה כלים מקצועיים:
פק״א, ניהול סיכונים ותחקיר.

המערכת היא Frontend בלבד. היא אינה כוללת התחברות, Backend, מסד נתונים,
שירותי צד שלישי או שליחת מידע. ההתקדמות נשמרת מקומית בדפדפן.

## הפעלה מקומית

דרישות: Node.js 20 ומעלה ו־npm.

```bash
npm install
npm run dev
```

לאחר ההפעלה יש לפתוח את הכתובת שמוצגת בטרמינל, בדרך כלל
`http://127.0.0.1:5173`.

## בדיקות ו־build

```bash
npm test
npm run build
npm run preview
```

ה־build הסטטי נוצר בתיקייה `dist`.

בפריסה לשרת סטטי יש להגדיר fallback של כל נתיבי היישום אל `index.html`,
מכיוון שהניווט מבוסס React Router. לדוגמה, ב־Netlify ניתן להוסיף כלל
`/* /index.html 200`, ובשרתי Apache/Nginx להגדיר rewrite מקביל.

## זרימת הלמידה

בכל אחד משלושת הנושאים קיימים אותם שלבים:

1. מבוא קצר ומיקום הנושא ברצף.
2. בנייה מודרכת של המסמך לפי תלויות אמיתיות בין חלקיו.
3. צפייה במסמך שהושלם.
4. תרגיל חיפוש טעויות ללא משוב מיידי.
5. תוצאות מפורטות לפי חלק במסמך.
6. סיכום, רמת שליטה ומעבר לנושא הבא.

## מבנה הפרויקט

- `src/app` — Router ומעטפת היישום.
- `src/components` — רכיבי UI משותפים.
- `src/pages` — ששת מסכי הזרימה וה־Roadmap.
- `src/content` — כל התוכן המקצועי, התרחישים, המשובים וה־config.
- `src/store` — Zustand ושמירת התקדמות.
- `src/services` — שכבת `StorageService`.
- `src/utils` — תלויות, בדיקת תשובות, ניקוד ומטריצת סיכון.
- `src/types` — טיפוסי תוכן והתקדמות.
- `src/tests` — בדיקות יחידה ללוגיקה המרכזית.

## עדכון תוכן

כל התוכן המקצועי נמצא ב־`src/content/modules.ts`. רכיבי ה־UI אינם מכילים
את התשובות או המשובים.

להוספת אפשרות Builder:

1. מאתרים את הנושא ואת `documentSections`.
2. מוסיפים אפשרות למערך `options`.
3. מגדירים את המזהה שלה ב־`correctOptionIds` אם היא נכונה.
4. מוסיפים משוב ייעודי לנכון ולשגוי.

להוספת תרחיש Review:

1. מוסיפים אובייקט ל־`reviewScenarios`.
2. מגדירים `annotationBank`.
3. לכל `documentBlock` מגדירים `expectedAnnotations`; מערך ריק מסמן חלק
   תקין.
4. מגדירים `explanation` מקצועי שמוצג לאחר ההגשה.

משקלי הניקוד, סף החזרה, גרסת התוכן ומטריצת הסיכון נמצאים
ב־`src/content/config.ts`.

## שמירת התקדמות ופרטיות

המידע נשמר תחת המפתח `military-profession-learning:v1` ב־localStorage.
נשמרים סטטוסים, תשובות, ניסיונות ותוצאות בלבד. אין שדות לשם, מספר אישי או
מידע רגיש.

שינוי `CONTENT_VERSION` מאפס באופן בטוח מידע שאינו תואם לגרסת התוכן.

## נגישות

- המסמך מוגדר `lang="he"` ו־`dir="rtl"`.
- כל החלקים הלחיצים הם כפתורים או controls סמנטיים.
- קיימים focus נראה, קישור דילוג, `aria-live` למשוב וניווט מלא במקלדת.
- מצבים אינם מסומנים באמצעות צבע בלבד.
- התנועה מכבדת `prefers-reduced-motion`.
